# Background music tracks not included in this copy

The six `bgm-*.mp3` tracks (about 28 MB) were removed from this copy of the skill on 2026-09-30 so the
repository download stays under 30 MB. The sound effects in `assets/sfx/` are still here.

The skill's video export still works; `add-music.sh` needs a music file you supply. To get the original
tracks, copy them from the upstream project this skill came from: https://github.com/alchaincyf/huashu-design
(folder `assets/`, files `bgm-*.mp3`), and place them in this `assets/` folder.
