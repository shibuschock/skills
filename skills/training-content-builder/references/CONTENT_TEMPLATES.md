# Content templates

Templates for each deliverable. All anchor on the module's **learning objectives** and the project's tone (learner-friendly, plain language, American English). Use `[SCREENSHOT: …]` / `[CONFIRM: …]` for any system specific you can't verify.

---

## Facilitator guide

```
# <Module title> — Facilitator Guide
Audience: <audience>   Duration: <min>   Modality: <ILT/VILT>
Objectives (learners will be able to):
- <objective 1 — Bloom verb>
- <objective 2>

## Prep & setup
- Environment/sandbox needed, logins, materials, room/tech.

## Flow (timed)
| Time | Segment | What the facilitator does | Learner activity |
|------|---------|---------------------------|------------------|
| 0:00 | Hook / WIIFM | Why this matters to THEM (tie to their real task) | — |
| 0:05 | Demo | Show the task step-by-step | Watch |
| 0:15 | Guided practice | Walk them through in the sandbox | Do it with prompts |
| 0:30 | Independent practice | Step back | Do it unaided |
| 0:40 | Check + Q&A | Run the assessment / task check | Demonstrate mastery |

## Talk track
<Key things to say per segment — concise prompts, not a script to read.>

## Practice activities
<Scenario(s) tied to objectives, with setup + expected outcome.>

## Answer key
<For each assessment item / practice task.>

## Common questions & pushback
<Anticipated friction (from the CIA change_considerations) + how to respond.>
```

## Job aid / quick reference (one page)

```
# <Task> — Quick Reference
WHEN: <trigger / when you'd do this>
1. <action> 2. <action> 3. <action>
⚠ Watch out: <the one thing people get wrong>
Need help? <where>
```
Keep it to a single side. Point-of-need, steps only, no theory.

## Slide outline

```
# <Module title> — Slide Outline
S1 Title
S2 Why this matters (WIIFM)
S3 What's changing (current → future, 1 line each)
S4 Objective overview
S5–Sn  One idea per slide; demo screenshots as [SCREENSHOT: …]
   - Headline: <single takeaway>
   - Notes: <speaker notes>
Sn+1 Practice
Sn+2 Check your understanding
Sn+3 Where to get help / next steps
```
One idea per slide. Speaker notes carry the depth; slides stay light.

## Assessment items

```
# <Module title> — Assessment
Measures objectives: <list>   Mastery: <threshold>   Kirkpatrick: L2

1. [Apply] <task or scenario question>
   - Correct: <answer> | Why: <rationale>
2. [Analyze] <scenario with an exception>
   ...
```
Match each item's verb to its objective's Bloom level. Prefer task/scenario checks over recall quizzes for skill-based objectives — completion ≠ competence.
